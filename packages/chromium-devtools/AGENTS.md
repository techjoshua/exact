# Using eXact Chromium DevTools

See the [README](./README.md) for build, installation, and operating instructions. Use the extension
to inspect eXact component instances, state, tasks, microfrontends, and profiler captures in a
Chromium browser.

- Open the eXact panel on a page built with inspection enabled.
- Use Components for instance-level inspection and Profiler for grouped recorded activity.
- Keep automation read-only and use the agent package when programmatic access is required.
